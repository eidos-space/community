# Contributing

Website design, accessibility, localization, and behavior changes belong here.
Run `pnpm test`, `pnpm typecheck`, and `pnpm build` before opening a pull request.

To submit or update a plugin, theme, or extension, use
[eidos-space/registry](https://github.com/eidos-space/registry/blob/main/CONTRIBUTING.md).
Do not add a local catalog copy to this repository: development and production
consume the same public GitHub registry.

Deployments are performed locally by maintainers with `pnpm deploy`.
